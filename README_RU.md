## Основные проекты

### [Горы Staff](https://github.com/Mastn1kth/gory-staff)

Система управления рестораном и программой лояльности. Включает Expo React Native приложение, API на Node.js и Express, PostgreSQL, Socket.IO, offline-first сценарии и интеграции с iikoCloud, Twilio, OAuth и Cloudflare.

### AstraChat Onda

Веб и mobile мессенджер с акцентом на приватность. Построен на React, Express, PostgreSQL, Redis, WebSocket, WebRTC и Capacitor. Поддерживает личные чаты, группы, каналы, медиа, звонки, push-уведомления, модерацию, резервное копирование, горизонтальное масштабирование и автоматизированные тесты. Репозиторий пока приватный.

### LectureVault

Кроссплатформенное приложение для записи лекций и автоматического создания конспектов. Groq Whisper расшифровывает аудио, Gemini формирует структурированный Markdown, после чего заметка сохраняется в Obsidian. В Android-версии реализованы фоновая запись, возобновляемая очередь обработки, шифрование API-ключей и безопасная работа с файлами.

### [Goal Rings](https://github.com/Mastn1kth/goal-rings)

Flutter-приложение для Android и iOS: ежедневный план, прогресс-кольца, серии дней, восстановление после пропуска, локальное хранение, уведомления, виджет и дополнительный AI-помощник с offline fallback.

### Пульс клиники

React и TypeScript PWA для операционных процессов клиники: смены, задачи, проблемы, чек-листы, объявления, предложения команды, роли, журнал аудита, optimistic concurrency и зашифрованные резервные копии.

### Pet Translator AI

Развлекательное приложение на React Native и Expo с локальным распознаванием звуков животных через TFLite, анализом камеры, достижениями, уведомлениями, sharing и Android release-сборками.

### [Casino Mini App](https://github.com/Mastn1kth/casino-mini-app)

Демонстрационное Telegram Mini App на FastAPI, SQLite и WebSocket. Использует только виртуальные монеты и включает Telegram-аутентификацию, историю, таблицу лидеров и проверяемые seed для поддерживаемых игр.
