## Основные проекты

Ниже — либо открытые репозитории, либо точные описания объёма работы. Закрытые исходники и сторонняя кодовая база явно отмечены.

### [Горы Staff](https://github.com/Mastn1kth/gory-staff)

Система управления рестораном и программой лояльности. Включает Expo React Native приложение, API на Node.js и Express, PostgreSQL, Socket.IO, offline-first сценарии и интеграции с iikoCloud, Twilio, OAuth и Cloudflare.

### [AstraChat Onda](https://github.com/Mastn1kth/AstraChat)

Веб и mobile мессенджер с акцентом на приватность. Построен на React, Express, PostgreSQL, Redis, WebSocket, WebRTC и Capacitor. Поддерживает личные чаты, группы, каналы, медиа, звонки, push-уведомления, модерацию, резервное копирование, горизонтальное масштабирование и автоматизированные тесты.

### [LectureVault](https://github.com/Mastn1kth/lecturevault)

Кроссплатформенное приложение для записи и расшифровки лекций на Android, Windows, iOS и macOS. Записывает или импортирует аудио, отправляет данные через защищённый gateway обработки только после явного согласия, формирует структурированный Markdown-конспект и мини-тест и сохраняет их прямо в Obsidian vault. В последних версиях добавлены обработка в трее для desktop, клиенты Apple, безопасное подключение vault, восстановление после прерванной обработки, диагностика gateway и локальный Android fallback при заранее скачанной модели.

### [Logisim Lab](https://github.com/Mastn1kth/logisim)

Учебный форк Logisim-evolution для проектирования и моделирования цифровых схем. Добавлены кроссплатформенная функция Circuit Check / «Проверка схемы», русская локализация и готовые Windows/macOS-сборки со встроенной Java — студенту не нужно отдельно устанавливать среду выполнения.

### [Goal Rings](https://github.com/Mastn1kth/goal-rings)

Flutter-приложение для Android и iOS: ежедневный план, прогресс-кольца, серии дней, восстановление после пропуска, локальное хранение, уведомления, виджет и дополнительный помощник с offline fallback.

### [Пульс клиники](https://github.com/Mastn1kth/clinic-pulse)

React и TypeScript PWA для операционных процессов клиники: смены, задачи, проблемы, чек-листы, объявления, предложения команды, роли, журнал аудита, optimistic concurrency и зашифрованные резервные копии. Это операционный пилот, в котором явно исключены медицинские карты, диагнозы и данные о лечении пациентов.

### [Pet Translator AI](https://github.com/Mastn1kth/pet-translator-ai)

Развлекательное приложение на React Native и Expo с локальным распознаванием звуков животных через TFLite, анализом камеры, достижениями, уведомлениями, sharing и Android release-сборками.

### [Casino Mini App](https://github.com/Mastn1kth/casino-mini-app)

Демонстрационное Telegram Mini App на FastAPI, SQLite и WebSocket. Использует только виртуальные монеты и включает Telegram-аутентификацию, историю, таблицу лидеров и проверяемые seed для поддерживаемых игр.

### [AI/IT News Bot](https://github.com/Mastn1kth/ai-news-bot)

Telegram-автоматизация, которая собирает RSS и Atom источники, оценивает и удаляет дубли технологических новостей, ведёт локальные операционные данные и готовит посты на русском языке. Внешние сервисы подключаются через конфигурацию.

### [Telegram Business Booking Bot](https://github.com/Mastn1kth/telegram-business-booking-bot)

Бот записи для локального сервиса: слоты, напоминания, действия администратора, база клиентов, отчётность и экспорт в Excel. Использованы Python, aiogram, SQLAlchemy, Alembic, SQLite и опционально Redis для хранения состояний.

### [City News Moderation Bot](https://github.com/Mastn1kth/city-news-moderation-bot)

Telegram-workflow с участием модератора: собирает RSS, сайты и открытые каналы, готовит черновики, сверяет пересказ с источником и публикует только после подтверждения человека.

### [Telegram Movie Finder](https://github.com/Mastn1kth/telegram-movie-finder)

Telegram-бот для поиска фильмов и сериалов через TMDB: обычный и inline-поиск, карточки результатов, избранное и история. Даёт только метаданные и ссылки, без распространения защищённого контента.
